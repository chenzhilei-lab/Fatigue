  ---
  问题实质

  当前 v3.0 的做法（§2.3）：对三套标准统一用 ISO 的 $Y_{Sa} \approx 1.55$ 计算
  $\sigma_{F0}$，然后各自施加尺寸/表面修正。理由是"避免缺口效应重复计算"。

  但三套标准对应力集中的处理是完全独立、互不兼容的：

  ┌──────────────┬─────────────────────────────────────────┬──────────────────────────┬─────────────────────────────┐
  │              │                ISO 6336                 │        AGMA 2001         │             FKM             │
  ├──────────────┼─────────────────────────────────────────┼──────────────────────────┼─────────────────────────────┤
  │ 应力集中入口 │ $Y_{Fa} \cdot Y_{Sa}$ 嵌入              │ 几何因子                 │ 无 $Y_{Sa}$；用 $K_f$ +     │
  │              │ $\sigma_{F0}$                           │ $J$（内置应力集中）      │ 应力梯度修正                │
  ├──────────────┼─────────────────────────────────────────┼──────────────────────────┼─────────────────────────────┤
  │ 缺口敏感度   │ $Y_{\delta,\rm                          │ 内置于 $J$ 中            │ 内置于 $K_f$ 中             │
  │              │ rel,T}$（强度侧，降低许用应力）         │                          │                             │
  ├──────────────┼─────────────────────────────────────────┼──────────────────────────┼─────────────────────────────┤
  │ 论文实际做的 │ ✅ 原生正确                             │ ❌ 外挂一个 AGMA         │ ❌ 用简单几何系数替代 FKM   │
  │              │                                         │ 不存在的系数             │ 的梯度法                    │
  └──────────────┴─────────────────────────────────────────┴──────────────────────────┴─────────────────────────────┘

  ▎ "The resulting bias...is common to all AGMA and FKM runs and would not affect the relative ranking among switches

  降低 ISO 的 Y_Sa 后，标准间方差不仅没降，反而暴涨了 15.7 个百分点。

  原因

  降低 Y_Sa → ISO 的 σ_F0 变小 → ISO 预测的寿命大幅延长 → 大量 ISO 组合变成 run-out（N_cens 从 28 跳到 60）→ ISO 与
  AGMA/FKM 的距离拉大 → 标准间方差增加。

  这意味着什么

  当前论文的统一 Y_Sa=1.55 假设是保守的（conservative）——它实际上缩小了三套标准之间的差异。如果没有这个统一处理，标准间
  方差只可能更大（不会更小）。审稿人担心的"统一 Y_Sa 虚高了标准间方差"方向是反的。

  对于论文的辩护措辞，不能照抄你之前拟的那段话，应该改成：

  ▎ "If anything, the uniform Y_Sa assumption is conservative with respect to the standard-choice variance: reducing
  ▎ Y_Sa from 1.55 to 1.0 increases the standard-choice contribution from 30.1% to 45.8%, as ISO entries shift toward
  ▎ run-out and diverge further from AGMA and FKM. The qualitative conclusion—that standard choice is a first-order
  ▎ contributor—is therefore robust, and the reported 30.1% may be taken as a lower bound."
