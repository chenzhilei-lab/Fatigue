  # 二、正文与随附复现包之间的矛盾

  论文在 Data and Code Availability 中声明"reproduce.sh 可复现本文所有数值"，但 shipped 的 output/ 是混合版本，与正文多处冲突：

  - multi_torque_aft.json（2025-07-28 生成）在 700 N·m 给出 116 有限/28 截尾，而主分析 aft_anova.json/sweep.json（07-29）为 52 有限/92 截尾——同一扭
    矩两种截尾计数。600 N·m 处 shipped 文件有完整 AFT 分解（60 有限），而正文 Table 4 说"500/600 N·m 处 AFT 不可识别"。

  - multi_torque_anova.json 的三个扭矩块的 "torque" 字段全部为 700.0（500/600 块也写 700），属明显的元数据 bug。
  - sweep_summary.json 的扭矩字段写 350 N·m（实际按 gear_params.py 用 700 N·m 计算），run_sweep.py 的 docstring 还写着"972 combinations / 6
    switches"。

  - §4.12.5 引用 output/multi_aft_comparison.json 的 log-normal 分解（标准 45.7%、均值应力 27.6%、粗糙度 26.5%），并称之为"与 Table 2 一致"，但
    Table 2 是 43.7/26.4/25.4——同一模型同一数据集两个结果。

  # 三、公式与"可验证性"问题

  1. Basquin 参数与疲劳强度不自洽（§2.2.1）。按论文 Eq.(1) 与给出的 σf′、b，10^6 周处两条曲线都约 610 MPa；论文反复使用的 679/626 MPa（及"53 MPa 差
     异"）无法从这些参数导出。作者必须说明 679/626 的出处（代码注释显示它们来自本地文件"材料力学性能测试数据表.xlsx (SAE Phase data)"，而不是论文声
     称的 Waterloo SMDIdbase）——这是数据来源声明与代码/正文的冲突。

  2. Table 5 与截尾框架不相容。Table 5 的中位数（ISO 6.07、Gerber 6.56、P95=7.50）在"10^6 截尾"框架下不可能出现；这些值只可能来自"Basquin-only 无阈
     值外推"情景（threshold_sensitivity.json 的 bq_none，spread 6.0 dex）。§4.9 的 7.22、4.3 dex、1.9×10^4 均属此列，但 §4.9 把这段表述为基于 Table
     5 的基线结果。

  3. KA 敏感性分析有方法缺陷（ka_sensitivity.py）。脚本对 KA=1.25/1.5 只对有限寿命条目做解析缩放；run-out 条目一律保持 run-out（代码里"was run-out
     but now finite"分支直接 return inf，是死代码），所以三个 KA 水平截尾数恒为 92。这与正文"把工作点推到耐久极限之上"的物理描述矛盾，也会系统低估
     KA 对排名的影响。

  4. "native stress chain"校验的表述夸大。代码注释明确承认 Kt 是"calibrated engineering estimator, not a published formula"（原 Dolan & Broghamer
     引用被作者自己标注为错误），Kf(Neuber) 的 a′ 是"calibrated"值；正文却把这一校验描述为"Peterson/Neuber 计算"。同时 §2.3/§4.12.1 声称 ISO
     YSa=1.55、AGMA 1/J≈3.03、FKM Kf≈1.84"互相在 ±7% 以内"——但 1/J 与 YSa 相差约 95%、Kf 比 YSa 高 19%，"±7%"与同页的"Kf/YSa≈1.19（19%）"直接矛盾。
     Kf 取值在文中还有 1.84（Peterson）/1.75（Neuber）与"1.3–1.7"两套数字。

  5. 诊断统计与结论不符：Cox-Snell 残差 KS=0.49（n=144 时临界值约 0.11），均值 0.45 对目标 1.0，被描述为"acceptable agreement"，在统计学上站不住；
     §3.2/Fig.1 的 R²=0.966 与 aft_diagnostics.json 的 qq_plot_r_squared=0.9848 不一致；标准化残差偏度 −1.22 未报告。另外 bootstrap 的 95% CI（如均
     值应力 [33.3, 43.7]）不包含 Table 2 的点估计 26.4%，说明 bootstrap 验证的是 4 方法模型而非被当作主结果的 Table 2——§3.8/Fig.3 却说它"确认 Table
     2 的方差分数稳健"。

  6. 模型选择矛盾：log-logistic 的 AIC 比 log-normal 低 9.4，被称作"modestly better"，但论文随后以"结构等价于 Sobol'"为由保留 log-normal，且主分析
     的 log-normal 分解在 §4.12.5 与 Table 2 中又是两套数字。
