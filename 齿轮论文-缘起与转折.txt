     Engineering）现在要求多数据集验证（Paderborn、XJTU、IMS）。纯方法比较论文在机械 Q1 容易被 desk
     reject——除非你的方法学贡献是公认的新范式。

     方差分解角度确实新颖，但审稿人第一反应会是："你用 ANOVA
     在一个公共数据集上比较已知方法，机械工程的贡献在哪？"——你得说服他这事没人做过且有工程意义。

+1. 齿轮疲劳基础 —— ISO 6336 精读
+   - ISO 6336-3: 齿根弯曲强度计算（Bending stress σF）
+   - ISO 6336-2: 齿面接触强度计算（Contact stress σH）
+   - 核心公式：
+     σF = (Ft / b·mn) × YFa × YSa × Yε × Yβ × KA × KV × KFβ × KFα
+     σH = ZH × ZE × Zε × Zβ × √(Ft/b·d1 × (u+1)/u × KA×KV×KHβ×KHα)
+   - 许用应力：σFP = σFlim × YST × YNT × YδrelT × YRrelT × YX / SFmin
+   - 看明白即可，不用手算 —— 代码会算
+
+2. S-N 曲线（20% 精力）
+   - Wöhler 曲线：σa = σf' × (2Nf)^b （Basquin 方程）
+   - 关键：同一材料（42CrMo4 / AISI 4140）在不同数据库里有不同的 σf' 和 b
+   - 这是第一开关的来源
+
+3. 平均应力修正（20% 精力）
+   - Goodman: σa/σar + σm/σuts = 1
+   - Gerber: σa/σar + (σm/σuts)^2 = 1
+   - Morrow: σa/σar + σm/σf' = 1
+   - SWT: σar = σmax × εa × E（应变-寿命法）
+
+4. 应力集中系数（10% 精力）
+   - Peterson: Kf = 1 + (Kt - 1) / (1 + a/r)
+   - Neuber: Kf = 1 + (Kt - 1) / (1 + √(a'/r))
+   - 直接 FEM = CalculiX 取 notch root σmax / σnominal
+
+5. 累积损伤（10% 精力）
+   - Miner 法则：D = Σ(ni/Ni)，D=1 时失效
+   - Modified Miner: D=0.7~1.0（不同标准不同阈值）

+6. CalculiX 入门（半天）

+"""
+fatigue_models.py — Five-switch fatigue life calculation framework
+==================================================================
+Each function = one switch. The main pipeline loops over all
+combinations and outputs fatigue life Nf (cycles to failure).
+
+Analogous to: calibration_formulas.py in the metallicity project.
+"""
+
+import numpy as np
+from gear_params import (
+    GEAR, LOAD, MATERIAL, SN_CURVES,
+    Kt_SOURCES, MEAN_STRESS_METHODS,
+    DAMAGE_METHODS, SIZE_SURFACE_STANDARDS,
+    LOAD_SPECTRUM, rho_F,
+)
+
+
+# ═══════════════════════════════════════════════════════════
+# SWITCH 1: S-N Curve Source
+# σa = σf' × (2Nf)^b  →  Nf = 0.5 × (σa/σf')^(1/b)
+# ═══════════════════════════════════════════════════════════
+
+def compute_fatigue_life_sn(stress_amplitude, sn_source="MatWeb"):
+    """
+    Returns Nf (cycles) for given stress amplitude and S-N curve source.
+    If stress < endurance limit, returns ∞ (run-out).
+    """
+    curve = SN_CURVES[sn_source]
+    sigma_f_prime = curve["sigma_f_prime"]
+    b = curve["b"]
+    endurance_limit = curve["endurance_limit"]
+
+    if stress_amplitude <= endurance_limit:
+        return np.inf  # infinite life (run-out)
+
+    # Basquin: σa = σf' × (2Nf)^b
+    Nf = 0.5 * (stress_amplitude / sigma_f_prime) ** (1.0 / b)
+    return Nf
+
+
+# ═══════════════════════════════════════════════════════════
+# SWITCH 2: Stress Concentration Factor Kf
+# Kt → Kf via notch sensitivity q (Peterson or Neuber)
+# ═══════════════════════════════════════════════════════════
+
+def compute_Kt_geometric():
+    """
+    Theoretical stress concentration factor for gear root fillet.
+    Uses Dolan & Broghamer (1942) approximation for standard involute gears.
+    Returns Kt (dimensionless).
+    """
+    mn = GEAR["module_mn"]
+    r = rho_F  # root fillet radius
+    h = 2.25 * mn  # full tooth depth
+    t = np.pi * mn / 2  # tooth thickness at root (approx)
+
+    # Kt ≈ 1 + 0.5 × sqrt(t/r) × (t/h)^0.3  (empirical, ISO 6336 annex)
+    Kt = 1.0 + 0.5 * np.sqrt(t / max(r, 0.1)) * (t / h) ** 0.3
+    return Kt
+
+

+    """
+    Fatigue notch factor Kf from Kt + notch sensitivity q.
+    """

+# ═══════════════════════════════════════════════════════════

+grand_mean = y.mean()

+# Compute SS for each factor (Type-I sequential, but we average over orders)
+# For a balanced full-factorial design, Type-I = Type-II = Type-III
+SS_factors = {}
+n_total = n_valid

+for j, f in enumerate(factors):
+    group_means = {}

+        mask = X[:, j] == level
+        if mask.sum() > 0:
+            group_means[level] = y[mask].mean()

+    # SS = sum over groups of n_k × (mean_k - grand_mean)^2
+    ss = 0.0

+"""
+soh_models.py — Six-switch SOH estimation framework
+====================================================
+Six methods to estimate State-of-Health from the same aging data.
+Analogous to fatigue_models.py in the gear project.
+"""
+
+import numpy as np
+import warnings
+warnings.filterwarnings('ignore')
+
+
+# ═══════════════════════════════════════════════════════════
+# SWITCH 1: SOH METRIC
+# ═══════════════════════════════════════════════════════════
+
+def soh_from_capacity(cycle_data):
+    """SOH = C_current / C_initial (gold standard, but needs full discharge)"""
+    C_now = cycle_data['capacity_true_Ah']
+    return C_now  # actual capacity returned, normalized later
+
+
+def soh_from_resistance(cycle_data):
+    """SOH = 1 - (R_now - R_initial) / (R_eol - R_initial)"""
+    return cycle_data['R0_true_mOhm']
+
+
+def soh_from_ica(cycle_data):
+    """SOH from ICA peak height ratio"""
+    return cycle_data['ica_peak_height']
+
+
+def soh_from_discharge_time(cycle_data):
+    """SOH proxy: discharge time ratio (fast field test, no full cycle needed)"""
+    return cycle_data['discharge_time_s']
+
+
+def soh_from_coulomb_counting(cycle_data, window='full'):
+    """
+    Coulomb counting on charge data.
+    window='full' → integrate full charge
+    window='partial' → 20-80% SOC window only
+    """
+    V = np.array(cycle_data['charge_voltage_V'])
+    t = np.array(cycle_data['charge_time_vector_s'])
+    I = 1.5  # CC current (A)
+
+    if window == 'full':
+        Q = I * (t[-1] - t[0]) / 3600  # Ah
+    else:  # partial 20-80%
+        v_min, v_max = 3.5, 3.9
+        mask = (V >= v_min) & (V <= v_max)
+        if mask.sum() > 2:
+            Q = I * (t[mask][-1] - t[mask][0]) / 3600
+        else:
+            Q = I * (t[-1] - t[0]) * 0.6 / 3600  # fallback
+    return max(Q, 0.01)
+
+
+def soh_from_voltage_sag(cycle_data):
+    """
+    SOH from voltage drop under load (10-second pulse proxy).
+    Higher voltage sag = higher internal resistance = lower SOH.
+    """
+    V_disc = np.array(cycle_data['discharge_voltage_V'])
+    # Voltage sag at start of discharge (first 10% of points)
+    n10 = max(len(V_disc) // 10, 3)
+    V_start = np.mean(V_disc[:n10])
+    V_nominal = 3.7
+    sag = V_nominal - V_start
+    return max(sag, 0.001)

+
+A battery recycler measures three retired EV cells. The capacity test
+says they are at 82--97\% state of health---prime candidates for
+second-life deployment. The internal resistance test says 84--91\%.
+But the voltage-sag test says they are all at 63\%, regardless of
+actual condition---a 20--34 percentage-point gap that determines
+whether a \$5000 battery pack is resold or shredded. We hold three
+synthetic lithium-ion cells with calibrated aging trajectories (67.7\%,
+84.2\%, and 92.4\% true SOH at 120 cycles) constant, and systematically
+vary five methodological choices that a testing engineer must make: the
+SOH indicator metric (capacity, resistance, voltage sag), the
+degradation fitting model (exponential, quadratic polynomial, linear),
+the fitting window (40, 80, 120 cycles), the normalization baseline
+(cycle 1, 5, 10), and the noise filter (raw, moving average, median).
+A full-factorial ANOVA over 729 combinations reveals that two factors
+account for 29.5\% of total SOH variance: the choice of fitting model
+(16.5\%, $F$=85, $p<10^{-15}$) and the choice of health indicator
+(13.0\%, $F$=34, $p<10^{-15}$). The remaining three factors---fitting
+window, baseline cycle, and noise filter---are statistically
+indistinguishable from noise (combined $<$1\%). Bootstrap validation
+(100 draws, seed 42) confirms the factor ranking is stable under
+resampling. We conclude that the battery health diagnostics community
+should prioritize consensus on degradation curve fitting standards
+and indicator calibration before refining noise-filtering or baseline
+protocols. The open-source framework generalizes to any cell chemistry
+or aging dataset.
